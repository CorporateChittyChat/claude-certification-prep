Start here

A study path for each track, from first video to exam day.

CCAO-F

Associate path

  1. Watch or skim the video series. Each episode ends with a worked practice question.
  2. Read the domain study guides for every move, trap and rule.
  3. Test yourself with the interactive mock exam and reread any domain it flags.
  4. The night before, run through the recap deck and the exam tips.
CCDV-F

Developer path

  1. Read the CCDV-F overview for the episode-by-domain map.
  2. Watch the video series, starting with Episode 00 on the exam itself.
  3. Build each episode's project from the companion code. Episodes 05–09 run without an API key.
  4. Test yourself with the interactive mock exam and each episode's PRACTICE.md (EP 04 onward).
